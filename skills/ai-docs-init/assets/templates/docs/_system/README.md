部署只安装维护所需的规则、配置和工具。参考包中的目录树、校验清单和交付验证记录是该参考包的生成附件，不作为目标项目事实或必需安装文件。

增量安装的目标项目另有 `installation.json`，记录实际托管的文件、入口区块和基线哈希。它服务于重复执行和升级，不登记业务条目数量，也不能代替结构检查或严格就绪检查。
