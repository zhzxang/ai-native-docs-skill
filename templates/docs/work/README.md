# work · 领域入口

任务状态、计划、会话日志、复盘和授权各有明确职责。默认任务状态只在 items 维护。

先匹配任务，再读取具体有效条目；不要默认读取全部模板、草案或归档。

| 入口 | 作用 |
|---|---|
| [授权 / 批准记录](approvals/README.md) | 集合 / 子领域 |
| [Backlog / Bug / 工作项](items/README.md) | 集合 / 子领域 |
| [项目日志 / Dev Log](logs/README.md) | 集合 / 子领域 |
| [复杂任务执行计划](plans/README.md) | 集合 / 子领域 |
| [复盘](reviews/README.md) | 集合 / 子领域 |

新增实例使用相应集合模板。没有有效实例时记录知识缺口，不能把空模板当项目事实。
