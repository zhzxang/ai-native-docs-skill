# 完成与交付的判定

## 任务完成
目标与验收条件满足；变更处于明确范围；必要检查真实执行且有可定位证据；未验证项和残留风险清楚；相关文档已更新或说明无影响；交接位置与唯一任务状态一致。无法满足条件时可以交付部分成果，但不能把工作项标成完整 done。

## 小变更
错字修正等低风险变更只需匹配其影响的检查，不要求长计划、全套测试或完整发布流程。保持证据与风险相称，不用形式化负担掩盖实际判断。

## 代码与测试
新增或修改断言应仍符合批准规范，不通过删除检查、伪造返回结果或降低标准来宣称通过。能够独立验证的内容交给脚本、测试、CI 或检查工具；AI 的自我陈述不是唯一证据。

## 合并与发布
合并需要对应评审和保护规则；部署需要环境、工件、授权和部署门禁；生产验证需要真实运行证据。任务 done 不自动代表合并、发布或生产验证。

## 文档完成
源、适用版本与范围清楚；没有未经处理的关键占位符；所需核验与批准记录可追溯；链接与结构有效。机械检查通过不代表业务、法律或安全语义正确。

## 中断与部分交付
记录已完成、真实检查、剩余、阻塞、未提交改动与下一步。停止相关未授权或不安全的动作，但可继续执行范围内的安全工作。不依赖聊天历史恢复任务。
