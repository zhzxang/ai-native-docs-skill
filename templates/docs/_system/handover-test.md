# 无历史上下文交接验收

## 测试目标
验证一个新会话能仅依赖仓库和已授权工具完成定位、行动与交接，而不是检验 AI 是否会复述文档。

## 准备
选一个低风险、可逆且已有验收标准的任务；记录起始提交、环境、允许操作和时间/费用预算。使用没有项目历史对话的新会话，提供任务 ID 与仓库入口，不补充隐藏背景。

## 观察项
| 检查 | 通过依据 |
|---|---|
| 按任务读取 | 能说清读取哪些资料及其必要性，没有默认扫完整文档库 |
| 区分权威 | 没把模板、草案、旧政策或外部评论当当前批准规则 |
| 定位实现 | 使用映射定位实际代码，不假设固定目录 |
| 限定行动 | 保持在任务和权限范围内，未以降低门禁来绕过失败 |
| 验证结果 | 报告真实运行的检查、版本与证据，明确未验证部分 |
| 文档一致 | 更新唯一权威记录或说明无影响，没有制造第二套状态 |
| 跨会话交接 | 下一步具体、阻塞明确，后续会话无需重新做已完成调查 |

## 记录方式
每次演练写入测试报告或复盘集合，关联任务。把失败原因转成具体修复项：缺路由、事实冲突、命令无效、权限模糊、缺测试或缺证据。不要仅靠继续扩张 AGENTS.md 解决所有问题。

## 通过不代表什么
该演练不证明所有任务可无人值守，不替代生产风险评估、实际权限控制、备份恢复演练或业务审查。
