# 工具入口适配

## 共享正文，薄入口
本套件以根 `AGENTS.md` 保存共享执行约定。AGENTS.md 是公开格式，但文件发现、作用域和组合行为依客户端而异；必须在实际工具和版本上验证。

Codex 的发现链与启动目录和配置有关，不保证从仓库根启动就预先读取所有子目录规则。Claude Code 可通过 CLAUDE.md 的导入机制引入根 AGENTS.md；导入不是按需加载整套文档的方法。Copilot 在不同功能中支持的指令文件和组合规则也不同。

## 安装方式
适配模板位于 `docs/automation/adapters/`。只有在你的客户端需要时才复制到对应发现位置。不要维护多份独立的长期规则，不要把整个 docs 通过导入放进启动上下文。

复制 Claude 入口模板到根目录后，`@AGENTS.md` 才相对于该位置生效；模板在 docs 中时不应被当作已安装入口。Copilot 模板中的文字引用不是平台级导入，必须通过实际任务检查是否加载并遵循共享正文。

## Skills 与普通工作流
`docs/automation/workflows/` 是按需阅读的普通操作文档，不会因目录名字自动成为 Skills。只有真正反复复用且值得封装的流程才包装成 Skill。Skill 规范定义 name、description、SKILL.md 及渐进式资源加载；发现目录仍依赖客户端。

本套件的 Skill 模板未安装、没有执行权限，也不包含任何生产密钥。启用前调整触发描述、引用路径、允许工具和执行环境。

## 验证
让客户端报告实际加载的指令来源；在根与一个有特殊规则的目录分别进行低风险测试；检查是否存在冲突、重复导入或过量上下文。升级客户端后重做关键加载验证。

权威参考及核验日期见 [来源说明](sources.md)。
